# مولد تقرير سرعة الموقع

تطبيق Next.js يقوم باستخراج أهم مؤشرات الأداء من PageSpeed Insights وGTmetrix PDF ثم يبني تقرير PDF أنيق بالوضع الفاتح وفق المواصفات المطلوبة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

> يتم الاستماع افتراضيًا على `http://localhost:3000`.

## نظرة سريعة على التدفق

1. **الصفحة الرئيسية `/`**
   - إدخال رابط PSI (اختياري لكن مفيد).
   - رفع ملف GTmetrix PDF (إلزامي).
   - اختيار اسم العميل، اللغة، ورفع لقطات قبل/بعد.
   - الزر يقوم بتحويل الملفات لبيانات base64 وإرسالها إلى `/api/process`.
2. **API `/api/process`**
   - يجلب JSON من PageSpeed Insights (موبايل + سطح المكتب).
   - يقرأ PDF باستخدام `pdf-parse` ويستخرج أهم القيم.
   - يبني كائن التقرير الموحد ثم يعيده للواجهة.
3. **صفحة `/preview`**
   - تعرض التقرير بصيغة HTML نظيفة RTL وتتيح تنزيل PDF.
4. **API `/api/generate`**
   - يحول البيانات إلى HTML عبر قالب Handlebars الموجود بـ`templates/report.hbs`.
   - يستخدم Puppeteer لطباعة الصفحة إلى PDF بنفس الهوية اللونية.

## المتغيرات البيئية

- `GOOGLE_API_KEY` (اختياري): مفتاح واجهة PageSpeed Insights في حال الحاجة لمعدل استعلام أعلى.

## حزم رئيسية مستخدمة

- `next`, `react`, `react-dom`
- `pdf-parse` لاستخراج النص من PDF.
- `puppeteer` لطباعة التقرير إلى PDF.
- `handlebars` لمعالجة القالب.

## ملاحظات إضافية

- يحفظ التقرير الموحد مؤقتًا في `sessionStorage` للمعاينة.
- يمكن تعديل القالب في `templates/report.hbs` ليعكس أي هوية بصرية إضافية.
- اللون، الخطوط، وRTL مطبقة حسب المواصفات البرتقالية/الكريمية.
